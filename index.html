A GPU inside your computer answers in under a microsecond. Over Wi-Fi it takes about 1.5 ms. The fix isn't more bandwidth. It's fewer trips. Come try it.

Be the protocol

One image question to Qwen-VL-8B takes about 1.5 s on a local GPU. It also makes about 20,000 GPU calls that each wait for an answer. Send that over Wi-Fi as is, then switch on the tricks and watch the clock.

An 800B model on a laptop?

WiCi's open-source InferSSD streams the experts of huge mixture-of-experts models from your SSD, so models far bigger than your RAM still run. You don't need the box for this part.

  1. Check your machine first

    Most failed installs hit a missing requirement halfway through. This script checks all of them in a few seconds.

    Apple Silicon Macor Linux + NVIDIA + CUDAPython 3.9+~475 GiB SSD

    Download pre-flight script

    sh inferssd-preflight.sh

  2. Install

    Builds from source into a private environment. No sudo, no edits to your shell profile.

    curl -fsSL https://github.com/wici-ai/inferssd/releases/latest/download/install.sh | sh

  3. Serve it

    Starts a web chat and an OpenAI-compatible API at http://127.0.0.1:8080/v1. The first launch downloads the model and measures your machine.

    inferssd serve -hf mrfakename/DeepSeek-V4.1-Flash-1017-GGUF
